# 書籍集合刪除與重設

本政策適用於要求刪除、清空、重設或重新開始的集合資料，不適用於一般程式碼維護。

本文件由 Agent 依類腳本結構解讀；實際命令與執行前提依各節規定。

## 解析刪除目標

```text
const 刪除邊界 = {
  textoria-text2ebook/ 是專案目錄，不是集合。
  「重新開始」通常只涉及指定集合的生成資料。
  不涵蓋原始來源、其他書籍、專案根目錄、Skill 或執行環境。
  舊集合沿用實際命名空間，不推定新路徑。
};
function 解析刪除目標(刪除要求, 實際集合) {
  辨識候選集合與要求範圍。
  if (不是單一集合或路徑過廣) {
    提出釐清，不執行刪除。
    return 等待明確目標;
  }
  保留根登錄檔與其他集合；規劃只移除獲確認集合的登錄項目。
  return 單一目標與明確刪除範圍;
}
```

## 辨識不可取代內容

```text
const 不可視為網站成品的資料 = {
  外部來源與 source/ 保存副本。
  content/全文.md 或舊版 clean/cleaned_text.md。
  metadata.json 與上傳書目原檔。
  materials/ 與替換歷史。
};
function 辨識不可取代內容(目標集合, 可用副本, 刪除範圍, 備份要求) {
  for (資料 in 不可視為網站成品的資料) {
    檢查是否另有可用副本。
    if (只要求刪生成結果) { 將該資料列入保留清單。 }
    if (唯一原始來源位於刪除目標內) {
      規劃在刪除前移至安全的專案來源資料夾，列明實際保留位置。
    }
  }
  if (範圍涉及刪除原始來源 && 缺少另行明確授權) {
    return 等待原始來源刪除授權，不刪除;
  }
  if (未要求備份) {
    計畫註明不自動建立備份，並在破壞性確認前說明。
  }
  Skill 改名或更新不授權刪除來源或任一命名空間。
  return 保留清單、來源搬移計畫與備份方式;
}
```

## 確認並執行具體計畫

```text
const 禁止刪除範圍 = {
  專案根目錄、.agents/skills/、.textoria-text2ebook/、其他集合、確認範圍外來源。
};
function 確認並執行具體計畫(具體刪除計畫, 目標路徑, 保存確認) {
  核實目標為選定集合目錄且不在禁止範圍。
  if (核實失敗) { return 停止刪除，釐清目標; }
  顯示集合名稱、完整路徑、確切刪除清單、保留資料與備份方式。
  要求輸入 Delete <collection_path>；提示以實際完整路徑替換變數。
  if (保存確認不符合目前顯示計畫及實際路徑) {
    return 等待具體確認，不接受模糊的「是」;
  }
  依確認計畫先保留必要來源副本。
  if (必要保留未成功) { return 停止刪除並說明問題; }
  僅刪除已顯示且確認的項目。
  if (完整集合刪除) { 只移除對應登錄項目，保留根登錄檔。 }
  return 實際刪除與資料保留結果;
}
```
