# 書籍集合刪除與重設

本政策適用於要求刪除、清空、重設或重新開始的集合資料，不適用於一般程式碼維護。

## 解析刪除目標

```text
辨識單一實際集合；目標不明或路徑過廣 → 停止並釐清。
「重新開始」通常只涉及該集合生成資料，不包含原始來源、其他書籍、
專案根目錄、Skill 或執行環境。
textoria-text2ebook/ 是專案層級資料夾，不是集合。
保留根登錄檔與其他集合；完整集合刪除後只移除已確認的登錄項目。
舊集合沿用其實際命名空間，不推定新路徑。
```

## 辨識不可取代內容

```text
逐項檢查是否另有可用副本：
  外部來源與 source/ 保存副本。
  content/全文.md 或舊版 clean/cleaned_text.md。
  metadata.json 與上傳的書目原檔。
  materials/ 及其替換歷史。
這些可能是唯一的人工或提供資料，不當作可丟棄網站成品。
只刪生成結果 → 保留上述內容。
唯一原始來源位於目標內 → 刪生成資料前移至安全的專案來源目錄，
                           並在計畫列明保留位置。
刪除原始來源 → 另需明確授權。
未要求備份 → 不自動建立；破壞性確認前說明不會自動備份。
Skill 改名或更新 → 不授權刪除來源或任一命名空間。
```

## 確認並執行具體計畫

```text
顯示 = 集合名稱、完整路徑、確切刪除清單、保留來源／人工素材、備份方式。
要求輸入 Delete <collection_path>，提示中以實際完整路徑替換變數。
模糊的「是」不確認無邊界目標。
只執行已顯示且獲確認的計畫。
完整集合刪除時：
  核實目標為選定集合目錄。
  保留必要來源副本。
  刪除該目錄並更新對應登錄項目。
禁止刪除 = 專案根目錄、.agents/skills/、.textoria-text2ebook/、
           其他集合、確認範圍外的來源。
```
