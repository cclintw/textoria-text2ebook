# 輸入與書籍集合解析

本文件由 Agent 依類腳本結構解讀；實際命令與執行前提依各節規定。

## 解析任務與集合

```text
const 集合解析規則 = {
  能力詢問不寫入集合資料；討論、Skill 維護與製書分別處理。
  書目與前置頁附件不加入正文合併，也不取代確認點。
  正式書名在書目階段確認；改書名不改資料夾。
  slug 為小寫拼音／拉丁字母、連字號與碰撞後綴，不是使用者欄位。
};
function 解析任務與集合(使用者要求, 輸入檔案) {
  if (不是實際製書) { return 對應討論或維護範圍，不寫集合資料; }
  讀取 textoria-text2ebook/registry.json。
  if (存在 textoria-digital-library/registry.json) { 一併檢查舊登錄資料。 }
  if (多個集合可能符合) {
    詢問單一目標，不合併集合。
    return 等待集合釐清;
  }
  if (找到既有集合) {
    沿用實際集合。
  } else {
    依檔名或開頭標題提出暫定名稱。
    if (身分仍不明) { return 等待身分釐清; }
  }
  依本節格式表分類每份檔案。
  return 已辨識集合與輸入角色;
}
```

| 輸入角色 | 支援格式 |
|---|---|
| 正文 | TXT、Markdown、HTML/HTM、指定正文欄位的 CSV |
| 基本書目 | 對話、CSV、XLSX、JSON、TXT、Markdown |
| 封面 | 使用規定素材檔名的 JPEG、PNG |
| 書名頁、版權頁 | 使用規定素材檔名的 TXT、Markdown |

## 整併多份正文

```text
const 合併依據 = {
  優先序：使用者明示順序、編號檔名、卷章標記、自然排序。
};
const 合併規則 = {
  檔案邊界不自動代表文件或章節層級；維持一份可編輯全文。
  CLI 僅接受一個位置來源，不虛構多檔旗標。
  保留所有原始來源溯源，不將合併檔當成唯一原始來源。
};
function 整併多份正文(原始來源清單, 保存的順序確認) {
  依合併依據提出順序。
  if (目前順序尚未明確確認) {
    顯示順序並詢問。
    return 等待合併順序確認;
  }
  for (來源 in 原始來源清單) {
    保存原始來源、檢查結果、順序與邊界紀錄。
  }
  依已確認順序建立供 CLI 使用的單一工作來源。
  return 工作來源與各原始來源溯源;
}
```

## 審閱章節結構

```text
const 結構判斷依據 = {
  Markdown／HTML 明確標題：強結構證據。
  重複的純文字標記：可能構成章節證據。
};
const 結構審閱規則 = {
  信心值只描述證據，不代表確認。
  每個新章節版本遵循主指引的審閱與標題編輯說明。
  不修改原始來源；連結必須指向實際供編輯的工作檔。
};
function 審閱章節結構(工作全文, 衍生目錄, 保存審閱狀態) {
  if (同一目前版本已有有效明確確認) { return 目前版本已確認; }
  while (目前章節版本尚未確認) {
    依結構判斷依據呈現推定層級。
    顯示工作全文、衍生目錄的實際連結及主指引要求的說明。
    使用者回覆 = 等待使用者回覆。
    if (尚未回覆) { return 等待目前版本確認，保留審閱狀態; }
    if (使用者取消或暫停) { return 已取消或已暫停，保留工作檔; }
    if (要求修改或已直接編輯) {
      將變更套用至工作全文標題。
      重新產生目錄並更新審閱版本。
      continue;
    }
    if (明確確認目前版本) { return 目前版本的明確審閱決定; }
    釐清回覆，不將模糊回覆當成確認。
  }
  return 保存狀態中的有效審閱決定;
}
```
