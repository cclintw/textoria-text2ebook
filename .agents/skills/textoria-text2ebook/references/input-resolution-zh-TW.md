# 輸入與書籍集合解析

## 解析任務與集合

```text
區分一般討論、Skill 維護、實際製書。
能力詢問 → 不寫入集合資料。
製書 → 檢查 textoria-text2ebook/registry.json，
       以及存在時的 textoria-digital-library/registry.json。
找到目標 → 沿用集合。
多個集合可能符合 → 先釐清，不自動合併。
```

| 輸入角色 | 支援格式 |
|---|---|
| 正文 | TXT、Markdown、HTML/HTM、指定正文欄位的 CSV |
| 基本書目 | 對話、CSV、XLSX、JSON、TXT、Markdown |
| 封面 | 使用規定素材檔名的 JPEG、PNG |
| 書名頁、版權頁 | 使用規定素材檔名的 TXT、Markdown |

```text
書目與前置頁附件不得混入正文合併，也不取代順序確認點。
依檔名或開頭標題提出暫定集合名稱；僅在身分不明時詢問。
正式書名於書目階段確認。
slug 使用小寫拼音／拉丁字母、連字號與碰撞後綴；不是使用者欄位。
書名變更不重新命名集合資料夾。
```

## 整併多份正文

```text
合併前 → 顯示順序並取得確認。
排序依據優先序 = 使用者明示順序 → 編號檔名 → 卷章標記 → 自然排序。
保存每份原始來源、檢查結果、排序與邊界紀錄。
維持一份可編輯全文；檔案邊界不自動等於文件或章節層級。
CLI 僅接受一個位置來源參數：
  不虛構多檔旗標。
  先解析並保存多份輸入，再建立 CLI 使用的單一工作來源。
  保留所有原始來源的可追溯資料，不將合併檔冒充唯一來源。
```

## 審閱章節結構

```text
Markdown／HTML 明確標題 → 強結構證據。
重複的純文字標記 → 也可能構成章節證據。
信心值只描述證據，不代表確認。
每個新章節版本 → 遵循主指引的章節審閱與標題編輯說明。
顯示可編輯全文及衍生目錄的實際連結與推定層級。
等待明確確認。
有修改 → 修改工作全文標題，重建目錄，再審閱新版本。
禁止修改原始來源；禁止提供暫存連結卻要求編輯另一份檔案。
```
